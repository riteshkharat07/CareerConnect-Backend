# CareerConnect Backend

A job portal backend application built using Spring Boot and MySQL.

## Features
- REST APIs for job listings
- Job details retrieval
- Job application submission

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven

## Run Locally
1. Configure your MySQL database.
2. Set the `DB_PASSWORD` environment variable in your IDE run configuration.
3. Run the Spring Boot application from IntelliJ IDEA.

## API
- `GET /api/jobs` — Retrieve available jobs
- Application API — Refer to the controller mappings in the source code.
